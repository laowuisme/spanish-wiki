**Meaning:** next time

**Pattern:** Fixed phrase. *La próxima vez* + que + subjunctive = next time that... *La próxima vez que vengas* = next time you come. See [[vez-vs-tiempo]] — *vez* = countable instance of time.

**Example:** *La próxima vez, llega a tiempo.* — Next time, arrive on time.
