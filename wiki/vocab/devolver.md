**Meaning:** to return (something), to give back, to vomit (colloquial)

**Pattern:** Stem-changing verb (o→ue): `devuelvo, devuelves, devuelve...`. `devuelve` = he/she returns it. Pair with `volver` (to return/come back) — `devolver` specifically means to return an object.

**Example:** *¿Cuándo devuelves el libro?* — When are you returning the book? / *Lo queremos devolver.* — We want to return it. (raw/2026-08-08_session.md)
