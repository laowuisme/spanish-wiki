## Rule

**Ya no** = *no longer / not anymore*. It negates a previously true state.

- **ya** alone = *already* or *now* (positive context)
- **ya no** = *no longer* (negates a current or ongoing state)
- **todavía no** = *not yet* (different — implies it hasn't happened yet)

| Spanish | English |
|---|---|
| Ya habla español. | He already speaks Spanish. |
| Ya no hace frío. | It's no longer cold. |
| Ya no trabajo aquí. | I no longer work here. |
| ¿Todavía no has comido? | Haven't you eaten yet? |

## Common Patterns

- **Ya no + verb** (present) → "no longer does X": *Ya no me gusta el café.* = I no longer like coffee.
- **Ya + verb** (positive) → "already / now does X": *Ya entiendo la regla.* = I understand the rule now.
- **Contrast with *todavía***: *todavía* = still; *ya no* = no longer; *todavía no* = not yet.
