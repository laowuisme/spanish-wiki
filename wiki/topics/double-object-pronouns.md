# Double Object Pronouns — Yo se lo presté

## Rule

Sometimes a sentence needs **both** an indirect object pronoun (who receives the action: me/te/le/nos/os/les) and a direct object pronoun (what is being acted on: lo/la/los/las) at the same time.

### Order: indirect object comes first

`[indirect object pronoun] + [direct object pronoun] + verb`

- `Yo se lo presté.` — I lent it to him/her. (`se` = to him/her, `lo` = it)
- `Se lo mandaste.` — You sent it to him/her. (`se` = to him/her, `lo` = it)

### The special case: le/les → se

This is the part that trips people up. When the indirect object pronoun **le** or **les** is immediately followed by a direct object pronoun starting with `l-` (`lo`, `la`, `los`, `las`), **le/les changes to se**:

| Indirect | + Direct | Expected (wrong) | Actual form |
|---|---|---|---|
| le | lo | ~~le lo~~ | **se lo** |
| le | la | ~~le la~~ | **se la** |
| les | los | ~~les los~~ | **se los** |
| les | las | ~~les las~~ | **se las** |

This `se` is **not** the reflexive `se` — it's purely a spelling/pronunciation fix to avoid the awkward `le lo` sequence. Context (not the pronoun itself) tells you who "se" refers to.

- `Le presté el libro a Ana.` → `Se lo presté (a Ana).` — I lent it to her (Ana).
- `Les mandé la carta a mis padres.` → `Se la mandé (a mis padres).` — I sent it to them (my parents).

`me`, `te`, `nos`, `os` do **not** change — only `le`/`les` become `se` before a direct object pronoun.

## Common Patterns

| Sentence | Breakdown |
|---|---|
| `Yo se lo presté.` | se (=le, to him/her) + lo (it) + presté |
| `Se lo mandaste.` | se (=le, to him/her) + lo (it) + mandaste |
| `¿Me lo puedes dar?` | me (to me) + lo (it) — no se-change since it's `me`, not `le` |
