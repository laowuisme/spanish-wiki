# tan vs muy — So vs Very

## Rule

Both `tan` and `muy` intensify adjectives and adverbs, but they are used in different grammatical structures:

**muy** — "very" — used as a standalone intensifier before adjective/adverb
- `Es muy bonito.` — It's very pretty.
- `Habla muy rápido.` — He speaks very fast.

**tan** — "so" — used in comparisons or exclamations
- `Es tan bonito que...` — It's so pretty that...
- `¡Qué tonto!` (alternatively: `¡Es tan tonto!`) — He's so dumb!
- Used in `tan... como` (as... as) comparisons: `Es tan alto como yo.` — He's as tall as me.

### Key distinction
- `muy` = intensifier alone: `Es muy raro.` (It's very strange.)
- `tan` = sets up a consequence or comparison: `Es tan raro que nadie lo entiende.` (It's so strange that nobody understands it.)

You cannot substitute one for the other: `*Es tan raro.` (without a following clause) sounds incomplete in most contexts, while `*Es muy raro que nadie lo entiende` misuses muy.

## Common Patterns

| Pattern | Example | Translation |
|---|---|---|
| muy + adj/adv | `Es muy difícil.` | It's very difficult. |
| tan + adj + que | `Es tan difícil que lo dejé.` | It's so difficult I quit. |
| tan + adj + como | `Es tan alto como tú.` | He's as tall as you. |
| ¡Qué + adj! (exclamation) | `¡Qué difícil!` | How difficult! / So difficult! |
