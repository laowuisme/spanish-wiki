# Affirmative Commands — Haz, Sal, Pásamelo...

## Rule

An **affirmative command** (affirmative imperative) tells someone *to* do something. This is the mirror image of [[negative-commands]], and the two differ in two ways: the verb form itself, and where the pronoun goes.

### Regular tú commands = the él/ella present-tense form

For regular verbs, the affirmative tú command is identical to the third-person singular present indicative:

| Infinitive | él/ella present | Affirmative tú command |
|---|---|---|
| hablar | habla | **¡Habla!** |
| comer | come | **¡Come!** |
| escribir | escribe | **¡Escribe!** |

### Irregular tú commands — eight to memorize

A small set of common verbs have a short, irregular affirmative tú command that does **not** follow the "él/ella form" rule:

| Infinitive | Affirmative tú command | Example from notes |
|---|---|---|
| hacer | **haz** | *Haz la compra.* — Do the shopping. |
| salir | **sal** | *Sal y ayúdame.* — Go out and help me. |
| tener | **ten** | *...y ten cuidado.* — ...and be careful. |
| decir | **di** | *Di la verdad.* — Tell the truth. |
| ir | **ve** | — |
| poner | **pon** | — |
| ser | **sé** | — |
| venir | **ven** | — |

### Pronoun placement — the opposite of negative commands

With a reflexive or object pronoun, the pronoun **attaches to the end** of the affirmative command (as one word), rather than going before the verb:

- `¡Cálmate!` (Calm down!) — reflexive pronoun attached
- `Ayúdame.` (Help me.) — direct object pronoun attached
- `Pásamelo.` (Pass it to me.) — **two** pronouns attached: `me` (indirect object) + `lo` (direct object)
- `Tómala.` (Take it.) — direct object pronoun attached
- `Cómetelos.` (Eat them up.) — reflexive `te` + direct object `los`, both attached
- `Descríbemela.` (Describe her/it to me.) — indirect `me` + direct `la`, both attached

Compare to the negative form, where the same pronouns go *before* the verb as separate words: `No te calmes`, `No me lo pases`.

### The written accent on double-pronoun commands

When one or two pronouns attach to a command form, Spanish keeps the original spoken stress by adding a written accent if the word would otherwise be misread as stressed on a different syllable:

- `pasa` (stressed on *pa-*) + `me` + `lo` → **pásamelo** (accent added to keep the stress on *pá-*)
- `ayuda` (stressed on *a-yu-*) + `me` → **ayúdame** (accent added to keep the stress on *yú-*)
- `describe` + `me` + `la` → **descríbemela**

Without the accent, the stress would shift to the second-to-last syllable by default Spanish stress rules, changing the pronunciation.

## Common Patterns

| Affirmative command | Translation | Verb |
|---|---|---|
| `Haz la compra.` | Do the shopping. | hacer (irregular) |
| `Sal y ayúdame.` | Go out and help me. | salir (irregular) + ayudar (+ pronoun) |
| `Pásamelo y ten cuidado.` | Pass it to me and be careful. | pasar (+ 2 pronouns) + tener (irregular) |
| `Di la verdad.` | Tell the truth. | decir (irregular) |
| `Tómala.` | Take it. | tomar (+ pronoun) |
| `Cómetelos.` | Eat them up. | comer (reflexive + pronoun) |
| `Descríbemela.` | Describe her/it to me. | describir (+ 2 pronouns) |
