# Negative Commands — No te preocupes, no hables, no comas...

## Rule

A **negative command** (negative imperative) tells someone *not* to do something. Unlike affirmative commands, negative tú commands do **not** use the plain present-tense form — they borrow the **present subjunctive** ending, with the vowel "flipped":

| Infinitive type | Affirmative tú | Negative tú | Ending |
|---|---|---|---|
| -ar (hablar) | habla | **no hables** | -es |
| -er (comer) | come | **no comas** | -as |
| -ir (escribir) | escribe | **no escribas** | -as |

The trick: take the `yo` form of the present tense, drop the `-o`, and add the *opposite* vowel ending (`-ar` verbs get `-es`, `-er/-ir` verbs get `-as`).

### Reflexive pronoun placement

This is the key contrast with affirmative commands. With a **reflexive** or object pronoun:

- **Affirmative command** → pronoun *attaches* to the end: `¡Cálmate!` (Calm down!), `¡Levántate!` (Get up!)
- **Negative command** → pronoun goes *before* the verb, as a separate word: `No te preocupes.` (Don't worry.), `No te levantes.` (Don't get up.)

So `No te preocupes` = `No` + `te` (reflexive pronoun for *preocuparse*) + `preocupes` (subjunctive form of *preocupar*).

## Common Patterns

| Negative command | Translation | Verb |
|---|---|---|
| `No te preocupes.` | Don't worry. | preocuparse (reflexive) |
| `No hables tan rápido.` | Don't speak so fast. | hablar |
| `No comas eso.` | Don't eat that. | comer |
| `No te vayas.` | Don't go / leave. | irse (reflexive) |
| `No lo hagas.` | Don't do it. | hacer (+ object pronoun) |
