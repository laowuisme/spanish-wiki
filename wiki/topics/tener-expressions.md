# tener Expressions — Sensations and States

## Rule

Many physical and emotional states that English expresses with "to be" are expressed in Spanish with `tener` (to have) + a noun. This is a fixed pattern that must be memorised.

### Core tener expressions

| Spanish | Literal | Meaning |
|---|---|---|
| `tener hambre` | to have hunger | to be hungry |
| `tener sed` | to have thirst | to be thirsty |
| `tener sueño` | to have sleepiness | to be sleepy |
| `tener frío` | to have cold | to be cold |
| `tener calor` | to have heat | to be hot |
| `tener miedo` | to have fear | to be afraid/scared |
| `tener razón` | to have reason | to be right |
| `tener prisa` | to have hurry | to be in a hurry |
| `tener ganas de` | to have desire for | to feel like doing / to want to |
| `tener experiencia` | to have experience | to have experience |

### tener ganas de + infinitive
`Tengo ganas de beber algo.` — I feel like drinking something.

The structure: `tener ganas de + infinitive`. The noun `ganas` (desire, urge) is always plural.

### tener puesto
`Tengo puesto un sombrero.` — I have a hat on. / I'm wearing a hat.

`puesto` is a past participle used adjectivally here — it agrees with the thing being worn. `Tengo puesto` = "I have [it] put on".

## Common Patterns

| Expression | Example |
|---|---|
| tener hambre | `Tengo mucha hambre.` |
| tener razón | `Tienes razón.` — You're right. |
| tener prisa | `Tengo prisa.` — I'm in a hurry. |
| tener ganas de | `Tengo ganas de salir.` |
| tener puesto | `Tengo puesto el abrigo.` |
