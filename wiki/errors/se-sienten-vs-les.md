# se sienten mal (not les sienten)

## What Goes Wrong

Using `les` (indirect object pronoun) with `sentirse` (reflexive verb) instead of the correct reflexive pronoun `se`.

Mistake: `les sienten mal` — incorrect
Correct: `se sienten mal` — they feel bad

## Why It Happens

`sentirse` is a reflexive verb — it takes reflexive pronouns (me, te, se, nos, os, se), not indirect object pronouns (me, te, le, nos, os, les). Though some forms look the same (me, te, nos), the third person forms are different: reflexive `se` vs. indirect object `le/les`.

When the subject is third person plural (ellos), the reflex is `se`, not `les`.

## Correct Usage

`sentirse` conjugation with correct reflexive pronouns:

| Person | Correct form |
|---|---|
| yo | me siento |
| tú | te sientes |
| él/ella | se siente |
| nosotros | nos sentimos |
| vosotros | os sentís |
| ellos | **se sienten** |

- `Se sienten mal.` — They feel bad. (correct)
- `Me siento preocupado.` — I feel worried. (correct)
